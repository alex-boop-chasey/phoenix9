# Try it

Once the agent service is set up, open the dashboard at `#/agent-next` and click through this list.

1. Type "show me all stale projects". Cards appear for the projects it finds. Click one card and check that the dashboard opens that project.
2. Ask it to open a project's settings page. The dashboard should move to that page by itself.
3. Ask it to turn build notifications on for a test project. An approval card appears. Click **Approve** and check that the switch is now on for that project.
4. Ask the same thing again, this time click **Deny**. Check that nothing changed and the agent says so.
5. Ask for something long, then press **Stop** while the reply is still arriving. The reply should stop at once.
6. Ask for another long reply and reload the page in the middle. When the page comes back, the reply should catch up and keep going.
7. Start a new conversation, then open the old one again from the history list. Its messages should all be there.
8. Look at the allowance bar. It should say in words how much of this month's allowance is used (plenty left, running low, or used up). It shows no money amounts.
